# TorrentNova

An original, modern torrent discovery, search, download management, and media application.

## Project Status

Initial project setup.

## Planned Features

- Discovery Center
- Torrent search
- Torrent details
- Download manager
- Library
- Media playback
- Plugin Manager
- Settings
- Dark and light themes
- Responsive desktop and mobile interface

## Development

TorrentNova is being developed as an original application using compatible open-source technologies where appropriate.

Third-party components and their licenses will be documented in `THIRD_PARTY_LICENSES.md`.
